# MeshCore South Australia

SA Mesh is the South Australian MeshCore community hub for people who want to join, test, improve or understand the local MeshCore network.

Use this page when you searched for **MeshCore South Australia**, **MeshCore SA** or **South Australia MeshCore** and need the practical community starting point rather than only a live dashboard.

## Start here

1. Read [Getting started with MeshCore](/meshcore/getting-started) before buying or changing hardware.
2. Use [Frequency & Settings](/meshcore/recommended-settings) for the current SA Mesh radio baseline.
3. Check the live [SA Mesh dashboard](https://sa.themesh.au/) and [SA Mesh map](https://sa.themesh.au/map) as supporting visibility tools.
4. Join the [SA Mesh Discord](https://discord.gg/w9b7EBNC8X) for community help, coordination and corrections.

## Local South Australian MeshCore baseline

South Australia currently uses the same core MeshCore radio baseline documented for SA Mesh:

| Setting | Value |
| --- | --- |
| Frequency | `923.125 MHz` |
| Bandwidth | `62.5 kHz` |
| Spreading factor | `8` |
| Coding rate | `8` preferred |

See [Frequency & Settings](/meshcore/recommended-settings) for the fuller guidance and cautions.

## Community roles

SA Mesh focuses on community onboarding, local documentation, safe starting settings and links to the shared tools. Operational dashboards, observers and repeaters may be run by different community members or organisations.

For new users, the safest path is usually a **MeshCore companion node** first. Do not start with repeater firmware unless there is a clear coverage reason and the community has agreed it helps.
