# MeshCore start here

MeshCore is a LoRa-based messaging and routing system used by SA Mesh community members for companion nodes, repeaters, room servers and local mesh experiments.

## Useful upstream links

- [MeshCore documentation](https://docs.meshcore.io/)
- [MeshCore flasher](https://flasher.meshcore.co.uk/)
- [MeshCore source](https://github.com/meshcore-dev/MeshCore)

## Local path

1. Read the upstream MeshCore basics.
2. Check the [SA local settings](./local-settings.md) page before changing radio parameters.
3. Use the [SA dashboard](https://sa.themesh.au/) and [SA map](https://sa.themesh.au/map) to understand nearby coverage.
4. Ask the community before publishing hard defaults or repeater changes that have not been field-tested.
