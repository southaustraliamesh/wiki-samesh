# Meshtastic Maps

:::info Source note
Migrated from the legacy SA:MUG Wiki.js Meshtastic page. Meshtastic is included for historical/community completeness; SA Mesh's current primary documentation path remains MeshCore. Validate firmware/app behaviour against current Meshtastic docs before treating settings as universal defaults.
:::

The legacy SA:MUG Meshtastic map page pointed users to the live community map:

- [map.peeringsa.net](https://map.peeringsa.net)

The map visualises public Meshtastic nodes and related community visibility data across South Australia.

## Map features

The legacy page described the map as showing:

- shared node locations;
- uplink status and RF coverage;
- MQTT-linked and offline nodes;
- gateway nodes and peer access points.

:::warning Location privacy
Only publish map position data you are comfortable sharing publicly. Use coarse/fixed positions for private sites where appropriate, and ask the community before adding shared infrastructure.
:::
