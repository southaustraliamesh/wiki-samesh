# Meshtastic Node Builds

:::info Source note
Migrated from the legacy SA:MUG Wiki.js Meshtastic page. Meshtastic is included for historical/community completeness; SA Mesh's current primary documentation path remains MeshCore. Validate firmware/app behaviour against current Meshtastic docs before treating settings as universal defaults.
:::

The legacy SA:MUG build page was a short index for outdoor Meshtastic node build examples tailored to the Australia/New Zealand region.

It focused on resilient, off-grid and long-range setups with enclosures, batteries, solar and suitable antennas.

:::warning Build and install safety
Outdoor nodes can involve batteries, waterproofing, heat, rooftops/elevated installs and lightning exposure. Do not transmit without a suitable antenna attached, and do not install elevated equipment without appropriate mounting, weatherproofing and electrical-safety planning.
:::

## Contributing a build

A useful build page should include:

- purpose and expected environment;
- device/board model;
- firmware and role;
- power source and charging details;
- enclosure and waterproofing notes;
- antenna/feedline details;
- mounting notes;
- photos or diagrams;
- known limitations and maintenance requirements.

:::tip Current wiki direction
For new fixed infrastructure, prefer documenting MeshCore repeaters under the MeshCore/Hardware sections unless the build is specifically Meshtastic.
:::
